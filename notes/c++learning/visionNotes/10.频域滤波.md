## 频域滤波
### 频率直觉
- 低频：变化缓慢 = 大片平缓区域（天空、墙面）
- 高频：变化剧烈 = 边缘、纹理、噪点
- 低通 = 保留低频去掉高频 = 模糊/去噪；高通 = 相反 = 锐化/提取边缘
### 频谱图怎么看
- 中心 = 低频（主体），四周 = 高频（边缘细节）
- 频谱中某个方向亮 → 原图有该方向的边缘（竖边缘 → 横向亮痕）
- 需要 log 压缩显示：低频幅值远大于高频，直接显示全白
- 低频默认在四角，显示前要做象限交换（fftshift）搬回中心
### 混叠（aliasing）
采样频率追不上高频变化时，高频"伪装"成低频（车轮倒转、锯齿、摩尔纹）
工程结论：缩小图像前先低通滤波（防混叠）
### dft 流程
```
灰度图 → merge(实部=图, 虚部=0) → dft → 中心化
      → split → magnitude(√(Re²+Im²)) → +1 → log → normalize → 显示频谱
```
```cpp
// 1. 扩展最优尺寸
int m = getOptimalDFTSize(src.rows);
int n = getOptimalDFTSize(src.cols);
Mat padded;
copyMakeBorder(src, padded, 0, m - src.rows, 0, n - src.cols, BORDER_CONSTANT, Scalar::all(0));
// 2. 合成复数（双通道：实部=图，虚部=0）
Mat planes[] = { Mat_<float>(padded), Mat::zeros(padded.size(), CV_32F) };
Mat complexI;
merge(planes, 2, complexI);
// 3. 变换
dft(complexI, complexI);
// 4. 中心化（四象限对角交换，低频搬中心）
int cx = complexI.cols / 2, cy = complexI.rows / 2;
Mat q0(complexI, Rect(0, 0, cx, cy)), q1(complexI, Rect(cx, 0, cx, cy));
Mat q2(complexI, Rect(0, cy, cx, cy)), q3(complexI, Rect(cx, cy, cx, cy));
Mat tmp;
q0.copyTo(tmp); q3.copyTo(q0); tmp.copyTo(q3);
q1.copyTo(tmp); q2.copyTo(q1); tmp.copyTo(q2);
// 5. 幅值 + log 显示
Mat pl[2];
split(complexI, pl);
magnitude(pl[0], pl[1], pl[0]);
Mat magI = pl[0];
magI += Scalar::all(1);
log(magI, magI);
normalize(magI, magI, 0, 1, NORM_MINMAX);
```
注意：dft 只认双通道复数，merge/split 只是打包/拆包，不涉及算法本身
