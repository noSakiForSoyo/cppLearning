### api
```cpp
erode(src,erosion_dst,element);
dilate(src,dilation_dst,element);
```
### 详细原理
一个src作为源矩阵，一个element作为结构元素对src进行操作。
element需要定义一个原点，当进行操作的时候若扫过区域与elment完全重合(腐蚀)或至少存在1个(膨胀)，则将原点赋值为1，反之，赋值为0。
在灰度图则体现为，
	用覆盖的矩形-element，得到最小值则被视为该原点的值
	用覆盖的矩形+element，得到最大值则被视为该原点的值
	
element定义 ：
```cpp
Mat element = getStructuringElement(erosion_type,Size(2*erosion_size+1,2*erosion_size+1),Point(erosion_size,erosion_size))
```
此处几项参数
	eroson_type 决定使用的卷积核的几何形状，分别为MORPH_RECT,MORPH_CROSS,MORPH_ELLIPSE.矩形，十字形，椭圆。
	Size定义尺寸并确保恒为奇数，防止偏移。
	Point确定原点。此处为中心像素
主要控制腐蚀程度的是size
