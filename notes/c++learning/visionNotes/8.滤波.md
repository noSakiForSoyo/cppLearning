## 滤波器
### api
```cpp
 filter2D(src, dst, ddepth , kernel, anchor, delta, BORDER_DEFAULT );
```
	1. src:源矩阵
	2. dst:目的矩阵
	3. ddepth:目标像素深度，传-1表示和src相同
	4. kernel:卷积核，通常为一个奇数阶数矩阵
	5. anchor:原点 传Point(-1,-1)默认中心
	6. delta:结果偏移量，默认0
	7. 类型参数：边界外推策略
原理：根据卷积核在图像上的移动来对图像进行加权操作。

注意：filter2D默认进行相关操作，卷积操作需要对kernel进行180度翻转

## 滤波概念
### 可分离核（1D→2D）
高斯核是"可分离"的：2D 高斯 = 水平 1D 高斯 × 垂直 1D 高斯
```cpp
// getGaussianKernel 返回 1D 核（列向量）
Mat kx = getGaussianKernel(5, 1.0);   // 5x1
Mat ky = getGaussianKernel(5, 1.0);   // 5x1
// 验证：2D核 = kx * ky.t()（列×行）
Mat kernel2D = kx * ky.t();           // 5x5
```
意义：1D 滤波两次（先横后竖）比 2D 一次少算很多次乘法——O(n) 变 O(2n)
### 三种模糊的选择场景
| 滤波器 | 适用场景       | 注意             |
| --- | ---------- | -------------- |
| 高斯  | 通用去噪、高斯噪声  | 最常用            |
| 中值  | 椒盐噪声（黑白斑点） | 对突兀噪点免疫，高斯对它无效 |
| 双边  | 既要降噪又保边缘   | 慢              |
|     |            |                |
