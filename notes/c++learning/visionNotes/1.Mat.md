不需要手动管理内存，自动释放
包含两方面内容：矩阵头（有大量信息），指向矩阵的指针
### 初始化
```cpp
//只复制头部
cv::Mat a,c;
a=cv::imread(argc[1],IMREAD_COLOR);//·传入参数初始化
cv::Mat b(a);
c=a;
//创建新的roi并设置边界
cv::Mat d(a,cv::Rect(10,10,100,100));//矩阵创建
cv::Mat e = a(Range::all(),Reabg(1,3));//行列边界创建


//完整复制
cv::Mat f = a.clone();
CV::Mat g;
a.copyTo(g);
```
当复制矩阵头部时候，矩阵会令计数器+1,销毁时则-1.

### 存储方法
opencv标准使用BGR的方式进行合成颜色，蓝绿红

### 显式创建
```cpp
int sz[2] = {2,2,2};
cv::Mat l(2,sz,CV_8UC(1),Scalar::all(0))
```
其中的sz为长宽高设定为2，然后3表示维度。8U表示为8位无符号数，C(1)表示单通道。Scalar::all(0)表示将所有的值初始化为0

```cpp
cv::Mat c = cv::Mat_<double>({3,3},{0,-1,0,-1,5,-1,0,-1,0});
```
### mat类的常用属性
```cpp
int sz[2]={2,2}
cv::Mat a(2,sz,CV_8UC1,Scalar::all(0));

a.cols//列数
a.rows//行数
a.step//以字节为单位时候的矩阵的有效宽度
a.elemSize()//每个单位的字节数
a.total()//矩阵中元素的个数
a.channels()//矩阵通道数
```
