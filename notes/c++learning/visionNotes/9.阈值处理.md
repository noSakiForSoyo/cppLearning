## otsu方法
### api
```cpp
threshold(src, dst, 0, 255, THRESH_BINARY | THRESH_OTSU);
```
#### api参数
第三个参数：传入阈值，固定传0
第四个参数：最大图值，当超过阈值的话就把值设定为该值。只有第五个参数的前两个类型会需要这个参数
第五个参数：处理的阈值的类型
	分别有：
		1. THRESH_BINARY 超过阈值变为白，否则黑 
		2. THRESH_BINARY_INV 超过阈值变为黑，否则白
		3. THRESH_TRUNC 超过阈值的变为阈值
		4. THRESH_TOZERO 低于阈值的变为0
		5. THRESH_TOZERO_INV 高于阈值的变成0
### 理解
目标：找一个阈值 t，把像素分成两类（灰度 ≤ t 和 > t），让两类"差得最远"
类间方差（衡量"差得远"的指标）： σ²(t) = w0 · w1 · (μ0 − μ1)²
w0、w1：前景/背景的像素数
μ0、μ1：前景/背景的平均灰度
### 手写实现
```cpp
void otsu(const Mat &src,Mat &dst){
    auto arr = getArr(src);
    int n = src.rows*src.cols;
    long long frontSize =0 ,backSize=n;
    long long frontSum = 0,backSum=0;
    double max =0,now = 0;
    uchar maxCount=0;
    for(int i = 0;i!=256;i++){
        backSum += i*arr[i];
    }
    for(int i = 0;i!=255;i++){
        frontSize += arr[i];
        backSize -= arr[i];
        frontSum += i*arr[i];
        backSum -= i*arr[i];
        double w0 = frontSum/(double)frontSize;
        double w1 = backSum/(double)backSize;
        now = frontSize*backSize*(w0-w1)*(w0-w1);
        if(now>max){
            max = now;
            maxCount = i;
        }
    }
    Mat lookUpTo(1,256,CV_8U);
    uchar *p = lookUpTo.ptr();
    for(int i = 0;i!=256;i++) i<=maxCount ? p[i] = 0 : p[i] = 255;
    LUT(src,lookUpTo,dst);
}
```
该方法传入两个参数，src和dst
