## 伽马矫正
### 函数
```cpp
Mat lookUpTable(1,256,CV_8U);
uchar *p =lookUpTable.ptr();
for(int i = 0;i!=256;++i){
	p[i] = saturate_cast<uchar>(pow(i/255.0,gamma)*255.0);
}
Mat res = img.clone();
LUT(img,lookUpTable,res);
```
