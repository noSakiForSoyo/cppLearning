迭代器提供对象的间接访问，相当于指针。
### 获取迭代器
```cpp
auto b = v.begin();
auto e = v.end();
```
### 获取常量迭代器
只读的
```cpp
auto a = v.cbegin();
auto b = v.cend();
```
## 得到迭代器指向的对象
```cpp
 *b
```
## 相关用法
###  循环判断逻辑
```cpp
for(auto it = tet.begin();
!it->empty()&&it!=text.end();
it++){
}
```
### 运算
#### 得到中间值
```cpp
auto it  = item.begin()+(beg+end)/2
```

## 注意事项
### vector操作失效
凡是使用了迭代器的循环体，不要向其所属容器添加元素
