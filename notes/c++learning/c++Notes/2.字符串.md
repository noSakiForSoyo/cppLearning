std::string
### 相关使用
###### getline函数读取行
	getline(std::cin,line),将输入的一行读取到line（丢弃换行符）
###### 判空
	line.empty();
###### 取长度
	line.size(); 该函数返回值为string::size_type类型，无符号整形数
###### 相加性。在两个字符串相加时候，需要至少一方是string类型
###### 范围for语句
处理每个字符时候可以用到for-each语句。
```cpp
//如果需要修改内容，用引用形式
for(auto &word : expression){

}
```
在处理for-rach语句时候，如果string是const类型，则[[1.变量#auto|auto]] word得到的类型为 const char * 类型
###### 变大小写
	一般使用<cctype>库的toupper和tolower的api（对单个字符操作）
