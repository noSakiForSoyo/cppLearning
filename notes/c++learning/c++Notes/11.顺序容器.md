## 总体
### 种类
	1, vector 可变数粗，快速尾部插入删除
	2. deque 双端队列，支持头尾插入删除
	3. list 双向链表，支持双端顺序查询
	4. forward_list 单向链表，支持单向查询
	5. array 固定大小数组,需事先声明类型和长度
	6. string 字符串
### 迭代器
[[4.迭代器|迭代器]]
```cpp
c.begin();//普通迭代器
c.rbegin();//反向迭代器
c.cbegin();//const迭代器
```
### 赋值
```cpp
c1 = c2;//cc1的大小将与右侧相等
swap(c1,c2)；
c1.swap(c2);//交换元素
seq.assign(begin,end);
```
#### 列表初始化
用std::initializer_list显式声明，后续用{}赋值时候生效
```cpp
class myclass{
public:
	myclass(std::initializer_list i){
	
	}
}
```
#### assign赋值
可以跨容器类型使用
```cpp
seq.assign(b,e);
```
将seq中的元素替换为b和e中间范围的元素，
```cpp
seq.assign(il);
```
替换为初始化列表il中的元素
```cpp
seq.assign(n,t);
```
替换为n个值为t的元素
#### swap
不对元素进行任何操作，只对容器的大小和内部数据进行交换
### 增加元素
#### push_back
使size++然后将元素拷贝后到尾端。此时数组内的值和传入的参数不属于同一个变量
#### push_front
list,deque支持首端插入
#### insert
vector，deque，list，string支持
```cpp
a.insert(iter,1);
```
在迭代器iter之前的一位上添加一个参数
```cpp
a.insert(end,10,1);
```
在end处开始添加10个元素为1的变量

insert有一个返回值，该返回值为指向insert所添加元素的指针
#### emplace类操作
相比于push类更加节省内存空间
会直接在容器内部的内存空间进行
### 删除元素
#### pop_back
从尾部删除一个元素
#### erase
```cpp
it = lst.erase(it);
```
删除迭代器it指向的元素，然后返回迭代器后面一位的迭代器
```cpp
it = lst.erase(it1,it2);
```
删除两个迭代器中间的的所有数据，然后返回it2后面一位的迭代器
### 容量操作
```cpp
vec.capacity()//获取当前容器容量
vec.reserve(n)//分配至少能容纳n个元素的内存空间
```
### 适配器
	1. stack 栈，先进后出
	2. queue 队列，先进先出
	3. priority_queue 优先队列，自动出最大值或最小值
stack和queue是基于deque实现的，可以用deque来拷贝初始化
priority_queue基于vector实现
#### stack
```cpp
stack<int> stk(deq);//deque赋值
stack<int> stk1;//空栈
stk.push(a);
while(!stk.isempty()){
	int value = stk.top();
	stk.pop();
}
```
#### queue
```cpp
q.pop();//返回首元素或者最高优先级元素，但不删除
q.front();//返回首或尾元素，但不删除
q.top();//返回最高优先级元素，但不删除。只适用于优先对列
```
