### static
使对象在第一次定义时初始化，然后在程序终止才会销毁
```cpp
size_t count_calls(){
	static size_t ctr = 0;
	retun ++ctr;
}
```
### 指针形参
在使用[[1.变量#指针|指针]]进行函数传参时，改变形参并不会使原有的实参发生改变
```cpp
void reset(int *ip){
*ip = 0;
ip = 0;
}
```
之后* ip变成0,ip所指向的地址不发生改变。所以推荐传递引用参数
### const 实参和形参
#### 普通变量
普通实参可以对const形参进行初始化，但是const实参不能对普通形参初始化。
```cpp
void fcn(int i);
void fcn(const int i);
```
上面两个声明属于同一个初始化
#### 指针传递
使用[[1.变量#指针|指针]]传递，所遵循规则为[[1.变量#const指针|const指针]]内涉及的顶层const和底层const
#### 引用传递
同[[#指针传递]]，遵循[[1.变量#const引用|const引用]]

### main函数
```cpp

}
```
第一个形参·表示字符串的数量，第二个形参指向在编译时传入的字符串(从argv[1]开始)
### 可变形参
#### initializer_list 形参
使用迭代器来遍历。其余和vector类似。
不同点是initializer_list内部元素为常量，无法修改
```cpp
void err_msg(initializer_list<std::string> err){

}
//调用
err_msg( {"aaa","ssss","vvv"} )
```
