###  内容输出
有两种输出方式，一种是追加（app），另一种是覆盖（无mode）
```cpp
    std::string s;
    std::ofstream out("a.txt",std::ios::app);
    std::time_t now = std::time(nullptr);
    s = std::ctime(&now);
    std::ostringstream oss;
    oss << s.substr(0,24)<<'\n';
    out << oss.str();
    return 0;
```
其中ofstream为文件输出流
ostringstream为字符构建流，用于构建整的字符串而非直接输出
