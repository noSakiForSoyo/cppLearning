## 相关
### 索引
索引为size_t类型。
### 底层为指针
链接到[[1.变量#指针|指针]]
```cpp
std::string nums[] = {};
std::string *p = &nums[0];
std::string *p2 = nums;
```
p和p2是相同的，都指向nums的首位地址
	则nums相当于直接取首位地址
### auto设置类型
链接到[[1.变量#auto|auto]]
```cpp
int a[10];
auto p3(&a[0]);
```
p3的类型为 int *
### 迭代器获取
可以用std::begin(a)和std::end(a)来获取首[[4.迭代器|迭代器]]器和尾[[4.迭代器|迭代器]]
```cpp
int a[10] = {1,2,33,45};
auto it = std::begin(a)
```
### 运算
利用指针进行的相关运算方面大部分与迭代器相似
除开相减得到的类型为ptrdiff_t
### c类字符串
相当于字符数组
#### 定义
```cpp
const char ca[] = "woxihuanwanyuanshen"
```
#### 相关函数
在对c类字符串操作时候不能用到运算符，只能用到以下的几种方法
```cpp
strlen(p);//获取p的长度，不包括空字符
strcmp(p1,p2);//比较p1-p2的大小，并返回
strcat(p1,p2);//将p2加到p1的后面，返回p1
strcpy(p1,p2);//将p2拷贝给p1,返回p1
```
传入此类函数时候，必须以空字符结尾
####  转换函数
[[2.字符串|string类字符串]]和c类字符串相互转换
用到了c_str()函数
```cpp
std::string s("hello");
const char *str = s.c_str();
```
该函数底层是直接用str指向了s的内存地址，所以如果改变s的话，可能会导致成为悬空指针，则推荐重新拷贝

std::vector<int> ivec(std::begin(int_arr),std::end(arr));

### 多维数组
#### 使用范围for遍历
在外层循环的控制变量应当声明为&[[1.变量#引用|引用类型]]
具体用法
```cpp
int ia[row][cnt];
for(auto &r :ia){
	for(auto &c : r){
	}
}
```
#### 使用指针遍历
指针相当于一个数组
	则在定义的时候可以将指针指向数组来代表多维数组
```cpp
int ia[3][4];
int (*p)[4]=ia;//初始化指向ia的第一行
//修改指向的行数
p = &ia[2]
```
遍历时候
```cpp
for(auto p = ia; p!=ia+3;p++){
	for(auto q = *p;q!= *p +4;q++){
	
	}
}
```
#### 使用迭代器遍历
```cpp
for(auto p =std::begin(ia);p!=std::end(ia);p++){
	for(auto q = std::begin(*p);q!=std::end(*p);q++){
	
	}
}
```
