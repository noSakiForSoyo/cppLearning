### this
this是一个指向本类的一个指针。调用：
```cpp
std::string name = this->name 
```
### 友元
指的是在类外定义的函数或类可以访问本类的private变量
只要在声明时加上friend前缀即可，然后在类内声明一下
### inline
详细见[[8.函数基础#内联函数|inline]] 作用相同
### 返回 * this
可以用来链式调用，a.f1().f2();
```cpp
class A{
public :
	A& f1(){
		return *this;
	} 
}
```
### const相关
const类函数只能调用const类函数，其传递给内部调用的函数是常量指针
```cpp
int get() const{

}
```

#### 初始化列表
当成员为const，引用等特殊类型时候只能被初始化列表初始化
#### 委托构造函数

	person(int i,int j,int k):a(i),b(j),c(j){

### 隐式类型转换
```cpp
void f1(person a){

}
f1(1);
```
相当于初始化了一个传参为1的person对象
抑制传参需要用到explicit关键字
### 聚合类
要求所有成员为public
类似于：
```cpp
class A{
public:
	int val;
	string s;
}
```
的类被成为聚合类
初始化操作：
```cpp
A a = {
	0,
	"dui"
}
```
### constexpr构造函数

### static
#### static变量
需要在**类内声明**加**类外定义**
```cpp
class cat{
public:
	static int count;
};
int cat::count = 0;

int main(){

}
```
后面所有定义的变量共享一个count。
也可和[[#constexpr构造函数|constexpr]]或者[[#inline]]联动，直接在内部初始化，不用类外定义
```cpp
static constexpr int count = 100;
```
#### static成员函数
静态函数只能调用静态变量且不具有[[#this]]指针功能
