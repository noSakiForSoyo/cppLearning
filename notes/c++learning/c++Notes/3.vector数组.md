###  用法
```cpp
std::vector<int> a(n,val) //n个值为val的元素
std::vector<int> a(n) //n个初始化的对象
std::vector<int> a{b,c,d,e} //初始化
```
### 常用api
###### 尾端增加元素
```cpp
a.push_back(10);
```
###### 判空
```cpp
a.empty();
```
###### 元素个数
```cpp
a.size();
```
###### 返回引用元素
```cpp
a[n];
```
	注意，不能对未初始化的元素进行下标操作。只能对已经初始化的对象进行访问。
###### for-each循环
```cpp
for(auto item:word){
}
```
需要注意的是，不应当在foreach循环中使用push_back添加元素。会导致foreach无法继续进行。详见：[[4.迭代器#vector操作失效|迭代器失效]]中
