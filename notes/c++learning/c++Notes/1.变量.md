## 注意事项
## 初始化
函数体外的变量一般初始化为空或0。函数体内则未被初始化
## 关键字
### extern声明关键字
	宣布声明一个变量而非定义。一般用于变量跨多个文件使用
### const限定符
	 定义常量，防止程序修改.默认仅在当前文件有效(可在初始化时由变量赋予值)
### 全局常量
涉及：[[#extern声明关键字|extern]] 和[[#const限定符|const]]联合使用时候可以在全文件内共享常量初始化
```cpp
//在.cpp文件内部声明并初始化
extern const int buffer = 100;
//在.h文件内部声明
extern const int buffer;
```


## 复合类型
### 引用 
	引用相当于给一个对象另起一个名字。在改变对象时，所声明的引用也会改变
```cpp
int i = 10;
int &j = i;
```
### 指针
指针使用 ***存地址符***  * 来声明，然后***取地址符***  &来获取指向地址的数据。
后续在使用时使用**解引用符** * 来对指针所指向地址的变量进行操作
#### 空指针
	nullptr ->等价于将指针初始化为0
#### void* 指针
	可用于存放任意对象的地址。但是是只读形的，无法确认该指针指向的对象是什么类型的
### 引用指针
```cpp
int *p;
int *&r = p;
```
	和int *r 类似
### const引用
涉及：[[#const限定符]]和	[[#引用]]
	可以在函数传递值的时候确保函数不会改变原有值。同时避免较大的对象的内存开销。一般int等基础类型可以直接传值。大型对象则传入：const object &i
### const指针
涉及： [[#const限定符]]和[[#指针]]
	存在4种写法：
		const int * p ->锁值
		int const * p ->锁值
		int * const p ->锁地址
		const int * const p ->锁值锁地址
	简单记为左锁值，右锁地址
用法：
```cpp
void printValue(const int *p) {
    std::cout << *p;
}
int a = 10;
const int b =10;
printValue(&a);
printValue(&b);
```
#### 顶层const
	可以改变值，但是不能改变地址。整形的常量指针
#### 底层const
	可以改变地址，但是不能改变值。整形常量的指针
### constexpr 变量
	确保在编译时就完成运算的常量表达式。可以用来代替宏定义。
```cpp
constexpr int i = 10
```
在使用constexpr 定义指针，指针会表现为常量指针的形式，即可变值，不可变地址的形式。为[[#顶层const]]
## 变量类型
### typedef 
	用来定义一个整体的变量类型，如char * 之类的
### auto 
auto会忽略变量的[[#const限定符|const]]和&[[#引用]]属性
	注意：
		如果使用[[2.字符串#相关使用||字符串的范围for]]用法并为auto &c时，所得类型为const类型。确保无法修改
### decltype
decltype：全称 declear type，相比auto可以完整地复刻属性
```cpp
int val = 10
const int &rx = val;
auto a = rx; //int a = rx;
decltype(rx) b = val; //const int &b = val;
```
注意，当decltype((a))，即两层括号时，固定认为(a)为表达式。则所得类型为引用类型。类型为int &
## 自定义数据结构
可以直接在定义完结构体后就声明变量
```cpp
struct saleData{
int a = 0;
int b = 0;
} name food;
```
## 运算符
### 箭头运算符
 ->，相当于对一个指针解引用并调用其内部对象或方法
 ```
 it->item;
 (*it).item;
 ```
