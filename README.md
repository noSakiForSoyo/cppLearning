# C++ & Machine Vision Learning

> 面向**机器视觉应用工程师**岗位的系统学习仓库。目标不是"算法研究"，而是**工程落地**：用 C++ 和视觉工具链，解决真实产线上的图像处理问题。

## 🎯 学习定位

本仓库服务于一个明确的职业方向——**机器视觉应用开发**：

| 阶段 | 内容 | 定位 |
|---|---|---|
| 基础 | C++（Primer 精读 + 练习） | 语言地基，工程必备 |
| 图像处理 | OpenCV 应用（灰度/HSV/直方图/阈值/形态学…） | 视觉核心能力 |
| 工业视觉 | Halcon（机器视觉工业标准工具） | 产线实战利器 |
| 上位机 | Qt（界面 / 图像显示 / 交互） | 完整交付能力 |

> **原则**：应用为主，手写为辅。手写 Otsu、手写容器等练习是为了**理解原理、拒绝黑箱**——只有知道底层怎么工作，应用层才不会被"玄学"卡住。但一切手写最终服务于工程应用。
